# Annunciator Grid Card v1.1.0

v1.1.0 is a major additive update focused on visual flexibility, alarm-panel behavior, paired-lamp layout, and a cleaner Home Assistant visual editor. Existing v1.0.2 configurations retain their established appearance and behavior unless a new v1.1 option is enabled.

## Highlights

- Six lamp shapes: Rectangle, Round rectangle, Pill, Square, Circle, and Indicator dot, with borders and bezels that follow the selected geometry.
- Vertical or horizontal paired lamps, automatic Pair IDs, and optional Split pill geometry with independently operating halves.
- Row and column spans with deterministic collision handling and pair compatibility.
- Panel, header, lamp, and spacer surface controls, including independent colors, borders, frames/bezels, rounded corners, and reversible None switches.
- Translucent illumination, corrected Retro diffusion, and Retro Flicker that yields to active alert animations.
- Normal, Dim OFF, Dim ON, Dim non-alert, Dim all, and Custom OFF/ON/ALERT brightness profiles at panel and lamp scope.
- Reusable panel appearance presets and visual-only per-lamp appearance presets.
- Text, Icon only, or Icon + selected lines content, custom font stacks, selectable icon size, and single or separate ON/OFF icon colors.
- Per-line ON/OFF/Unavailable/Unknown labels and ordered dynamic text rules.
- Entityless Derived lamps driven by rules watching Home Assistant entities.
- Optional ACTIVE, ALARM, UNACKNOWLEDGED, TOTAL, UNAVAILABLE, and editable Day/Week/Month/Year tallies.
- Independently visible and relabelable ACKNOWLEDGE, SILENCE, RESET, LAMP TEST, and CLEAR ACKNOWLEDGED controls.
- None, Media player, Script, and Advanced action alarm outputs, including Home Assistant's media browser, optional Silence scripts, correct SILENCE behavior, and re-sound when a new alarm arrives.
- Panel-default or per-lamp Manual/Automatic acknowledgement rearm.

## Visual editor

- Quick setup for normal lamp creation and Full editor for specialist controls.
- Short, remembered appearance sections and compact sentence-case labels.
- Navigator badges for Paired, Split pill, Span, Dynamic, Audible, and Override configurations.
- Display and Behavior summaries, safe display-setting copying, pair-safe bulk editing, group suggestions, live rule tracing, contrast warnings, and reset-to-inherited actions.
- Responsive brightness references and coalesced color-picker updates that remain stable during rapid editing.
- Correct unfinished-lamp handling, so Add paired lamp creates two real lamp halves rather than spacers.

## Reliability and compatibility

- Schema v3 migration preserves v1.0.2 defaults, legacy pairs, ACK identities, color precedence, header behavior, and 1×1 layouts.
- Automatic ACK rearm, alarm-output replacement/cleanup, SILENCE/new-alarm re-sound, Lamp Test, derived change alerts, responsive observers, spans, collision packing, and editor lifecycle handling were hardened.
- Malformed configuration is normalized defensively; incomplete or unsafe interactions remain non-clickable.
- The final validation set passed more than 626,000 non-browser checks, 24/24 desktop/mobile browser harness runs, package extraction/parity verification, and a live Home Assistant visual-editor smoke test.

## Installation

Install or update through HACS, or download `annunciator-grid-card.js` from this release and copy it to `<config>/www/`. Load it as a JavaScript Module at `/local/annunciator-grid-card.js`, then reload Home Assistant and hard-refresh the browser.
