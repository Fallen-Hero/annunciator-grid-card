# Annunciator Grid Card v1.0.2

v1.0.2 is a community-feedback and stabilization release focused on clearer everyday defaults, more flexible interactions, stronger appearance options, and additional hardening while retaining compatibility with existing configurations.

## Highlights

- Fixed standalone lamp ON-color rendering so standalone and paired lamps resolve the same active color.
- Added cross-entity Conditional Rules and **Force OFF** while retaining existing Force ON behavior.
- Added independently configurable **Tap / short press**, **Double tap**, and **Long press** actions per lamp.
- Interaction actions include More Info, Toggle, Turn On, Turn Off, Acknowledge, Clear ACK, and None, with optional alternate target entities for entity actions.
- Added gesture arbitration so a double tap or long press does not accidentally execute the tap action too.
- Added independent panel-wide **ACK ALL** and **CLEAR ACK** header controls with separate visibility switches. ACK ALL acknowledges only currently active alert channels and does not pre-ACK inactive lamps.
- Simplified new-lamp colors around **Standard ON/OFF** behavior: green ON, neutral OFF, and no alert by default.
- Retained optional **Severity** and **Custom ON/OFF** modes for advanced annunciator behavior.
- Reworked global colors as independently enable/disable-able overrides, including Frame and Panel overrides so panel themes can own their surfaces when desired.
- Removed redundant ON Window controls from the normal editor while retaining legacy configuration compatibility.
- Strengthened Classic, Avionics, and Neon panel themes so they are visibly distinct.
- Strengthened Plastic, Glass, Frosted, and Smoked lens materials in both Modern and Retro styles.

## Reliability and compatibility

- Existing v1.x lamps remain on a legacy color-compatibility path until explicitly converted to Standard, Severity, or Custom.
- Preserved legacy ON Window priority where configured while fixing the standalone blank-window regression.
- Preserved partial legacy severity fallback behavior for hand-written configurations that omit individual severity colors.
- Incomplete alternate interaction targets and incomplete cross-entity rule sources are safe no-ops and are surfaced by config validation.
- Hardened malformed decimal precision values so manual YAML cannot cause `toFixed()` range failures.
- Fixed very-long-hold/touch gesture edge cases and isolated diagnostics controls from lamp gestures.
- Fixed editor/runtime global-color default drift and seven-tab layout handling.
- Added expanded static and runtime regression tests to the repository test command, including dedicated header-ACK compatibility/stress coverage.
- Refreshed the README and added an in-depth v1.0.2 user guide, configuration reference, troubleshooting guide, migration guide, validation notes, and expanded examples.

Legacy single-header ACK settings remain supported: old Clear-only and ACK-All-only configurations keep their previous behavior, while new v1.0.2 visual-editor cards can show both standardized buttons. Existing configurations are intended to remain compatible. As always, test the release candidate in Home Assistant before updating a production dashboard.
