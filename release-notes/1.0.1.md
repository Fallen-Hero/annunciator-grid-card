# Annunciator Grid Card v1.0.1

v1.0.1 is a documentation and release-metadata update.

## Changed

- Updated the README displayed through GitHub and HACS.
- Improved version and release presentation.
- Prepared repository documentation for HACS default-catalog submission.
- Updated card/package metadata to v1.0.1.

## Compatibility

No functional annunciator behavior has changed from v1.0.0.

Existing dashboards, lamps, groups, paired lamps, acknowledgement settings, conditional rules, and helpers remain compatible.

## Installation

Existing HACS users can update normally when v1.0.1 becomes available.

> Annunciator Grid Card is a dashboard/monitoring component and is not a certified life-safety or process-safety system.
