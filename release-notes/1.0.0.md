# Annunciator Grid Card v1.0.0

The first public stable release of Annunciator Grid Card.

This release provides a Home Assistant annunciator-panel card with a full visual editor, alarm acknowledgement, grouped and paired lamps, conditional rules, numeric transforms, change alerts, persistent ACK state, responsive sizing, diagnostics, validation/repair, and accessibility-conscious interaction.

## Highlights

- No-YAML visual editor for normal configuration.
- Industrial alarm/status/sensor behavior with TRIP / ALARM / WARN / STATUS severity.
- Blink, Pulse, Wave, Throb, Heartbeat and Flash effects.
- Manual or automatic alarm rearm.
- Compact persistent ACK storage designed for normal Home Assistant `input_text` limits.
- Paired TOP/BOTTOM windows and group ACK controls.
- Auto Fit layout for desktop, tablet, mobile, Masonry and Sections dashboards.
- Ordered Conditional Rules and three-line display/value formatting.
- Lamp Test, diagnostics overlay, support-package copy, Undo and configuration repair.

## Installation

HACS users can add the repository as a **Dashboard** custom repository until it is accepted into the default HACS catalog.

Manual users should install the attached `annunciator-grid-card.js` as a JavaScript Module resource.

See the repository README and `docs/USER_GUIDE.md` for full setup instructions.

> This card is for monitoring/dashboard use and is not a certified safety system.
