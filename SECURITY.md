# Security Policy

Annunciator Grid Card is client-side Home Assistant dashboard JavaScript. It does not provide an independent authentication, authorization, safety, or security boundary.

## Reporting a security issue

For a suspected security issue, use GitHub's private security advisory/reporting feature if enabled for the repository rather than posting sensitive details in a public issue.

Include the affected version, Home Assistant version, reproduction steps, and the minimum information necessary to demonstrate the issue.

## Scope

Examples that are in scope include unintended script execution, unsafe handling of user-controlled content, or behavior that could expose Home Assistant data beyond what the logged-in frontend already permits.

Normal Home Assistant permissions, entity visibility, network security, and account security remain the responsibility of Home Assistant and the deployment administrator.
